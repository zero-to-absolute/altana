# Альтана

Веб-приложение чайного магазина «Альтана»: каталог чаёв, корзина, оформление заказа, личный кабинет и конструктор авторских смесей, который подбирает ингредиенты по совместимости с чаем. Дипломный проект, СПбПУ, 2026.

## Что внутри

- каталог с карточками чаёв, избранное и сохранённые рецепты;
- корзина, оформление заказа и история заказов;
- регистрация и вход;
- конструктор смесей: оценка совместимости чая и ингредиентов, расчёт пропорций.

## Тесты

60 модульных тестов на Vitest лежат в папке tests. Они проверяют валидацию форм входа и регистрации, оценку совместимости чая и ингредиентов, расчёт пропорций смеси, подбор рекомендаций и вспомогательные функции. Тесты запускаются командой `npm run test`, а в GitHub Actions выполняются перед каждой сборкой сайта: если хоть один тест упал, сайт не публикуется.

## Технологии

JavaScript (ES-модули), Vite, Tailwind CSS. Бэкенд на Supabase: PostgreSQL, аутентификация, хранилище файлов.

База данных проекта в Supabase удалена, поэтому [опубликованная версия](https://zero-to-absolute.github.io/altana/) показывает только интерфейс: без товаров, картинок из базы и входа в аккаунт.

## Запуск

Нужен Node.js 18 или новее.

```
npm install
npm run dev
```

Открыть в браузере адрес, который выведет команда. Двойным кликом по index.html приложение не откроется: ES-модулям и Tailwind нужен dev-сервер Vite.

Адрес и публичный ключ Supabase задаются переменными VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY.

Другие команды: `npm run build` собирает статику в папку dist, `npm run preview` показывает собранную версию.
